# VRC Nexus

Eigenständige Apps rund um VRChat – ohne Server, alle Daten bleiben auf deinem Gerät.

| App | Ordner | Build |
|---|---|---|
| 🖥️ Windows (Electron) | [`apps/vrc-nexus`](apps/vrc-nexus) | GitHub Actions „VRC Nexus App (Windows)“ |
| 📱 Android (Capacitor) | [`apps/vrc-nexus-android`](apps/vrc-nexus-android) | GitHub Actions „VRC Nexus App (Android)“ |
| 🎛️ Stream-Deck-Plugin | [`apps/vrc-nexus/streamdeck`](apps/vrc-nexus/streamdeck) | im Windows-Build enthalten |

Downloads: siehe **Releases**. Details und Änderungen stehen im README der jeweiligen App.

Die GHOST-NODE-Webseite (PHP-Dashboard) liegt seit dem Umzug in einem eigenen Repository.
